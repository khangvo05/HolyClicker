How to Use

After opening the scripting window, click ADD or press ENTER to add new entries. Each entry only contains one command. Your script will be executed sequentially.

Basic Commands

Comments
Use double slash for comments.
// This is a comment
cX,Y
Click at coordinate X, Y. Optional T for times.
click100,200,2
cIMG.PNG...
Find and click image. REGION (x1,y1,x2,y2) is optional.
clickbtn.png,(0,0,500,500)

Note: The image file must be located in the same folder as the HolyClicker executable.

Those scripts will be appended into the current list.

Note: Ensure your imported scripts follow the exact JSON format to avoid parsing errors.

Interval Between Commands

In the Editor window, INTERVAL is the sleep time between each command execution.

Command Usage

Below is the complete list of available commands with usage examples:

Comments
Use double slash to add comments to your script.
// This is a comment

Comments must be on separate entries.

clickX,Y
Move the cursor to coordinate X, Y.
click100,200
clickX,Y,T
Click at coordinate X,Y T times.
click100,200,3

T is optional (defaults to 1 if not provided).

clickIMG.PNG,COLOR,REGION
Click at the center of an image on screen. COLOR (true | false) determines whether to use color matching or not. REGION is the search area in format (X1,Y1,X2,Y2).
clickbutton.png,true,(0,0,500,500)

REGION is optional. Image files must be in the same directory as the executable.

waitTIME
Wait for specified seconds.
wait0.5
wait2.5

TIME must be divisible by 0.1.

waituntilTIME
Wait until specific time (HH:MM:SS).
waituntil14:30:00
Wait until a specific time of the same day. The format is HH:MM:SS.
waituntil14:30:05
typeTEXT
Type the specified text.
typeHello World
typerandomFILE,DEL
Type random line from file. Set DEL to true to delete line after typing.
typerandomdata.txt,true
pressKEY
Press a single key (e.g., enter, f5, esc).
pressenter
pressdownKEY
Press and hold a key.
pressdownshift
releaseKEY
Release a held key.
releaseshift
dragToX,Y,BTN,T
Drag mouse to X,Y using BTN (left/right) over T seconds.
dragTo500,500,left,1.5
mousedownX,Y,BTN
Hold mouse button at X,Y.
mousedown100,100,left
mouseupX,Y,BTN
Release mouse button at X,Y.
mouseup100,100,left

Nested Commands

IMPORTANT SYNTAX RULE
All advanced commands below MUST be followed immediately by a begin entry and closed with an end entry.
repeatN:
Execute the block N times.
repeat5:
begin
  click100,100
  wait1
end
untilCONDITION
Repeat the block of code until a condition is met.
  • untilIMG.png Repeats until IMG.png appears on the screen.
  • untilHH:MM:SS Repeats until the clock hits HH:MM:SS.
untillogin_btn.png
begin
  wait1
  pressf5
end
ifX,Y
Execute block ONLY IF mouse cursor is near (within 10px) of X,Y.
if500,500
begin
  typeMouse is here!
end
randomDISTRIBUTION
Randomly execute ONE command/block from inside the begin/end block.
  • randomUNIFORM Equal chance for all commands.
  • random0.7,0.3 Custom probabilities.
randomUNIFORM
begin
  click100,100
  click200,200
end

Warning for custom probabilities:

  • The sum of all probabilities must equal exactly 1.
  • The number of distributions must equal the number of commands in the block.
typeHello World!
pressBUTTON
Press and release a button.
pressenter
clickdownBUTTON
Press down a mouse button.
clickdownleft
releaseBUTTON
Release a mouse button.
releaseleft
mousedownX,Y,OPTION
Press down mouse at coordinates with specified button.
mousedown100,200,right
mouseupX,Y,OPTION
Release mouse at coordinates with specified button.
mouseup100,200,right

Advanced Commands

dragToX,Y,OPTION,t
Drag mouse to coordinates while holding button for t seconds
dragTo300,400,left,2
listenIMG.PNG,S,INTERVAL,N,TIME,COLOR,REGION
Watch for the image to appear on your current monitor for S seconds. If found, next N commands will be executed.
S : total time to watch for the image
INTERVAL : sleep time between each check
N : the number of next entries to execute
TIME : maximum number of execution when the image is found
COLOR and REGION(optional) options are the same as in click command.
listenpopup.png,10,0.5,3,2,true,(0,0,800,600)
clickpopup.png,true
click200,100
click175,100

This command can run in parallel with other operations.

randomcommandN,UNIFORM
Randomly execute one of next N commands with uniform distribution.
randomcommand3,uniform
click150,100
click200,100
click175,100
randomcommandN,P1,...,PN
Randomly execute one of next N commands with custom probabilities distribution.
randomcommand3,0.5,0.3,0.2,
click150,100
click200,100
click175,100

The sum of probabilities P1,...,PN must equal 1.

randomtypeFILE.*,DELETE
Randomly type a line from a text file. DELETE (BOOLEAN) is optional. If DELETE is true, the line will be removed from the file.
randomtypephrases.txt,true
repeatN:
Repeat the next commands N times until "end".
repeat5:
click100,100
pressf5
end
